{{- /* Renders a small status chip for an event: "Upcoming" while its event_date is still in the future (or happening now), "Past Event" once it has passed. Renders nothing when the given context has no event_date param, so it is safe to call unconditionally from templates shared with non-event content types (e.g. the generic single/card templates). Usage: {{ partial "components/event-status-chip" . }} */ -}} {{- with .Params.event_date -}} {{- $eventDate := partial "components/safe-time" . -}} {{- $isUpcoming := ge $eventDate (now) -}} {{ if $isUpcoming }}Upcoming{{ else }}Past Event{{ end }} {{- end -}}
